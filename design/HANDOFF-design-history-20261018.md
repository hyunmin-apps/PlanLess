5. 계획 레서의 별 눈빛/V, 열정 레서의 불꽃/폭죽을 각각 확인한다. 완료 마지막에는 효과가 사라진다.
6. 새 버전 폴더에 PNG·GIF·Pixelorama 원본·미리보기를 저장한다. 이전 버전은 덮어쓰지 않는다.
7. 프레임 수·해상도·투명 배경·재생 시간뿐 아니라 실제 시각적 움직임을 확인하고 결과를 보여준다.

## 도구와 검증 환경

- FFmpeg: `/opt/homebrew/bin/ffmpeg`
- FFprobe: `/opt/homebrew/bin/ffprobe`
- Pillow 사용 가능.
- Pixelorama 1.2.3 공식 앱을 작업 중 임시 복사해 사용했다. 현재 경로 존재 여부를 다시 확인:
  `/tmp/plan-captain-tools/Pixelorama.app/Contents/MacOS/Pixelorama`
- PXO는 ZIP 기반으로 data.json과 image_data/frames/N/layer_N raw RGBA를 포함한다. 기존 파일 구조를 먼저 확인한다.
- 검증했던 CLI 형태:
  `Pixelorama --headless --rendering-method gl_compatibility --quit -- --export --output /absolute/name.gif /absolute/name.pxo`
  출력 이름이 프로젝트 이름을 따를 수 있으므로 실제 생성 파일을 확인한다.
- CUA 브라우저 자동화는 file: URL 열기를 보안 정책으로 차단했다. 다른 브라우저·로컬 서버 등으로 우회하지 않는다. 로컬 파일/이미지 검증과 사용자에게 직접 여는 링크 제공은 가능하다. 브라우저 상호작용을 실제로 확인했다고 말하지 않는다.
