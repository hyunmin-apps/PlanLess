# PlanLess 레서판다 플래너 아이콘

사용자가 만든 승인 캐릭터 **계획단장 레서판다**를 중심으로 만든 앱 아이콘입니다. 안경·청록 스카프·크림색 얼굴 무늬·줄무늬 꼬리를 유지하고, 화면 왼쪽에 연필 하나, 오른쪽에 체크형 플래너 하나를 배치했습니다. 청록색 타일과 픽셀 아트로 앱에서 쓰는 캐릭터의 모습을 이어갑니다.

- 현재 원본: `source.png` — 내장 image_gen 도구로 생성한 결과 그대로.
- 캐릭터 기준: `../lesser-idle-tracking-v2/planner-approved-reference.png`.
- 최종 제작 프롬프트: `prompt.txt` (동일 원문 `redpanda-planner-prompt.txt`). 도구·해시 기록: `provenance.json`.
- 앱용 1024px PNG, 10개 표준 크기, ICNS: 프로젝트 루트에서 `python3 scripts/build-icon.py`.
- `mint-check-v1/`: 이전 민트 체크 아이콘과 제작 기록. 현재 앱에는 쓰지 않습니다.
- `previous-icon.swift`: 이름 변경 전 달력 아이콘의 과거 원본.

실행 중 캐릭터 프레임이나 애니메이션은 변경하지 않았습니다. 아이콘만 별도 제작한 것입니다.
