# 레서 — 통일 디자인 v5

## 보기
`preview.html`은 외부 파일 없이 열립니다. 두 캐릭터의 대기·진행 중·완료를 나란히 비교하고 정지·프레임 탐색을 할 수 있습니다. 실제 앱 적용 전 디자인 시안입니다.

## 이번 변경
- 이전 64px 파일을 확대하지 않고 고해상도 원본에서 캐릭터를 다시 추출했습니다.
- 128×128px 캔버스에 캐릭터와 머리 위 효과 공간을 배치했습니다. 캐릭터 기준 원본은 96×96px입니다.
- 캐릭터별 기준 그림 하나를 모든 상태에서 재사용합니다. 얼굴·의상·소품은 상태마다 새로 생성하지 않습니다.
- 전체 파일에 동일한 색상표와 선명한 외곽선을 적용했습니다.
- 완료 시 두 캐릭터 모두 같은 초록 V가 커지며 등장하고 위에서 튕긴 뒤 작아져 사라집니다. 이전 회전 체크와 폭죽은 교체했습니다.
- 진행 중: 계획 레서는 큰 파란 네 꼭짓점 눈빛, 열정 레서는 몸 뒤의 불꽃입니다.

## 편집 파일
각 상태 폴더에 개별 PNG 24장, GIF, 확대 GIF, Pixelorama `.pxo`가 있습니다. PXO는 뒤쪽 효과·고정 캐릭터·앞쪽 효과의 3개 레이어로 분리되어 있습니다. 완료 마지막 두 프레임은 V가 없습니다.

오픈소스 FFmpeg로 원본을 읽고 이미지 파일을 처리했으며, Pixelorama 1.2.3의 CLI에서 PXO를 실제로 열어 GIF를 내보냈습니다. MCP 서버를 사용한 것으로 표현하지 않습니다. Python 표준 라이브러리로 팔레트 고정·최근접 변형·효과 레이어·PXO 포장을 재현합니다. 기준 캐릭터는 앞서 만든 AI 보조 원본을 재사용했습니다. 이번 버전에는 새 AI 캐릭터 생성이 없습니다.

이번 모션은 통일감을 우선한 기준 그림의 호흡·눌림·점프와 별도 효과입니다. 손·팔을 개별 리깅해 새로 연기하는 애니메이션은 아닙니다. `build_assets.py`는 제작 기록이며 경로는 이 작업 환경 기준입니다.
