# 레서 v6 — 자세가 바뀌는 애니메이션

v5의 고정 그림 늘이기·줄이기를 진행 중·완료 동작에서 제거했습니다. 새 24프레임 원본에서 손·팔·머리·다리·꼬리 자세가 변합니다. 대기 동작은 v5 파일을 그대로 유지합니다.

`preview.html`에서 세 상태를 나란히 재생하거나 슬라이더로 자세를 확인하세요. 완료 효과는 비교를 위해 반복 재생하며, 마지막 프레임에는 사라집니다. 앱에 적용된 릴리스는 아닙니다.

- 출력: 투명 128×128 PNG, 각 상태 24프레임, 약 2초
- 진행 중: 계획표 쓰기·고개 움직임 / 배트와 주먹을 움직여 응원
- 완료: 준비 자세·점프·팔 들기·착지, 계획 레서는 초록 V 팝업 / 열정 레서는 불꽃 없이 폭죽
- 새 캐릭터 프레임에 공통 팔레트 적용
- Pixelorama `.pxo`: 새 동작은 자세 애니메이션과 완료 효과를 별도 레이어로 저장
- GIF·확대 GIF·개별 PNG·프레임 비교 이미지 포함

## 제작 기록
내장 이미지 생성 도구로 동일한 캐릭터 참조를 사용해 실제로 다른 자세의 프레임을 제작했습니다. FFmpeg로 원본을 분리하고 해상도·알파를 정리했으며, Python 표준 라이브러리로 공통 색상과 V·폭죽 효과를 적용하고 PXO를 포장했습니다. Pixelorama CLI에서 프로젝트를 실제로 읽어 GIF를 내보냈습니다. MCP 서버를 사용한 것은 아닙니다.

AI 보조 래스터 프레임이므로 세부 선과 소품에 프레임 간 차이가 남을 수 있습니다. 생성 프레임 전체를 하나의 정지 그림으로 대체하지 않았습니다. 몸동작은 생성한 프레임이며, V·폭죽 효과는 별도 제작입니다. 손·팔·다리가 각각 분리된 리깅 파일은 아닙니다.
