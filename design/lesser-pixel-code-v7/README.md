# 코드로 그린 레서 — 6프레임

이번 파일은 기존 AI 그림의 축소·재배열이 아닙니다. `draw_lesser.py`의 좌표·색상·그리기 함수로 캐릭터와 소품, 효과를 처음부터 그립니다. 입력 이미지와 AI 생성 호출은 없습니다.

## 보기와 편집
- `preview.html`: 자체 포함 미리보기. 두 캐릭터의 세 상태를 나란히 재생하고 1~6프레임을 확인합니다.
- `draw_lesser.py`: 실제 그림 제작 코드. Pillow를 설치한 환경에서 실행하면 PNG·GIF·PXO가 다시 만들어집니다.
- 각 상태의 `.pxo`: Pixelorama 편집 원본. 뒤쪽 효과 / 꼬리 / 몸·다리 / 머리·의상 / 팔·소품 / 앞쪽 효과의 6레이어.
- `sheet.png`: 6프레임 스프라이트 시트.
- `animation.gif`, `preview.gif`: 기본 크기·3배 확대 미리보기.
- 캐릭터 이름의 GIF: Pixelorama CLI에서 직접 내보내 검증한 파일.
- `all-frames.png`: 두 캐릭터·세 상태의 모든 자세를 비교하는 표.

## 동작
각 상태 6프레임, 128×128px. 팔 위치·팔꿈치·머리 각도·다리 자세·꼬리를 프레임별로 그립니다. 몸 전체를 확대·축소하는 애니메이션이 아닙니다. 핵심 자세마다 유지 시간을 다르게 설정했습니다.

계획 레서: 안경·청록 스카프·계획표·연필. 진행 중에는 쓰기와 고개 움직임, 파란 별 눈빛. 완료는 점프와 머리 위 V 등장·사라짐.

열정 레서: 빨간 머리띠·나무 배트. 진행 중에는 배트를 어깨에 올리고 주먹으로 응원하며 불꽃 효과. 완료는 불꽃 없이 점프와 폭죽. V 없음.

전체 팔레트는 `palette.json`, 재생 시간은 `manifest.json`에 있습니다. 실제 앱에 적용한 릴리스가 아닌 디자인 결과물입니다.

도구: Pillow의 정수 좌표 래스터 그리기, Pixelorama CLI의 PXO 읽기·GIF 내보내기, FFmpeg의 GIF 검증.
