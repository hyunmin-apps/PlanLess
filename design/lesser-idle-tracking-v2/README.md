# 레서 대기 시선 수정 v2

사용자가 거절한 머리 영역 분리·회전 방식은 사용하지 않습니다. 이미지 생성 도구로 방향별 전신 자세를 만들고, 목·스카프·어깨·몸통이 연결된 포즈를 80×80 투명 프레임으로 정리했습니다.

- 계획단장: 9개 방향 영역 + 중립 눈깜빡임 3프레임.
- 열정: 상/하/오른쪽 대각선 및 중립 자세. 왼쪽 3영역은 검토한 하나의 완만한 왼쪽 전신 포즈를 공유합니다. 과하게 목이 꺾이거나 머리띠 위치가 바뀐 대각선 수정본은 사용하지 않습니다.
- 시트 칸을 정사각형으로 늘이지 않습니다. 비율을 보존하고 캐릭터별 공통 배율을 적용합니다. 시트 경계의 고립된 조각을 제거하고 발 중심·바닥 y=74를 맞춥니다.
- 앱은 포즈 사이를 120ms 이상 유지하며 중간 자세를 거칩니다. 방향 경계에는 여유 범위를 둡니다. 머리나 얼굴을 잘라 붙이거나 따로 돌리지 않습니다.
- 진행·완료는 승인된 lesser-motion-v8 PNG 24장을 바이트 그대로 사용합니다. 대기만 교체했습니다.

제작: built-in image_gen. 원본과 프롬프트는 source-atlas PNG, prompts.json, left-prompts.json에 보관합니다. `passion-left-source.png` 가운데 포즈만 채택했습니다.

`tracking-review.gif`는 방향별 전신 포즈 확인용입니다. 실제 앱은 포인터 위치로 포즈를 선택하며, 이 GIF 순서를 자동 재생하지 않습니다. 앱 반영 파일은 Resources/Mascots, 재현 정리는 scripts/prepare-mascots.py입니다.

계획단장은 완전히 눈을 감은 생성 원본에서 안경이 사라져 해당 포즈를 제외했습니다. 반쯤 감긴 전신 포즈를 유지해 안경이 깜빡이며 없어지지 않도록 했습니다.
