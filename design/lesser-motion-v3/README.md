# 레서 모션 · 효과 버전

계획단장 레서와 열정 레서, 각각 대기·진행 중·완료 세 가지 상태를 담은 픽셀 애니메이션 디자인입니다. 앱에 적용된 릴리스는 아닙니다.

`preview.html`을 열면 두 캐릭터를 함께 보고 상태를 선택하거나 한 프레임씩 확인할 수 있습니다.

- 프레임: 투명 배경 64×64 PNG, 캐릭터별 공통 24색 이하
- 캐릭터별 24포즈, 상태별 8포즈. 동작별 노출 시간을 다르게 설정했습니다.
- `planner/planner.pxo`, `passion/passion.pxo`: Pixelorama에서 편집하는 원본. 프레임별 단일 래스터 레이어이며 신체 부위가 분리된 리깅 모델은 아닙니다.
- `idle.gif`, `working.gif`, `complete.gif`: 상태별 애니메이션
- `*-preview.gif`: 최근접 보간으로 4배 확대한 미리보기
- `sheet.png`, `sheet.json`: 스프라이트 시트와 Pixelorama 내보내기 정보
- `manifest.json`: 상태 범위와 프레임별 재생 시간
- `source-atlas.png`: AI 생성 원본. 실제 사용 파일은 저해상도로 정리한 PNG입니다.

## 동작

| 상태 | 계획단장 레서 | 열정 레서 |
|---|---|---|
| 아무것도 안 하는 중 | 호흡·눈 깜빡임 | 배트에 기대 쉬기 |
| 진행 중 | 파란 눈빛·계획표 체크 | 불꽃·응원 |
| 완료 | 체크 동작·머리 위 체크 효과 | 불꽃 종료·폭죽·점프 |

## 제작

내장 이미지 생성 도구로 캐릭터 포즈와 효과를 만들고, FFmpeg로 64px 픽셀 및 공통 팔레트를 정리했습니다. Pixelorama 1.2.3에서 PXO 파일을 실제로 읽고 GIF·PNG 시트를 내보냈습니다. 3D 모델이나 손으로 전 픽셀을 그린 작업이 아닌 AI 보조 2D 스프라이트입니다.
