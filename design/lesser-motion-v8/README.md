# 레서 v8 — 80px · 6프레임 · 소품 연속성 수정

2026-10-18 (Asia/Seoul). v6의 실제 자세 변화를 기준으로 골랐던 핵심 자세를 저해상도 이미지 편집으로 정리했습니다. 사용자가 지적한 펜·방망이 중복과 어색한 손 위치를 반영해 네 동작을 하나씩 다시 편집하고 확인했습니다.

`preview.html`을 직접 열면 상태 선택, 재생/정지, 완료 다시 보기, 프레임 탐색, 밝은/어두운 배경을 사용할 수 있습니다. PNG 데이터를 내장해 서버가 필요 없습니다. `overview.gif`는 네 동작을 함께 보는 반복 비교 자료입니다.

## 수정 내용

- 계획 진행 중: 연필은 화면 왼쪽 손에 하나, 계획표는 오른쪽 손에 하나. 다섯 번째 자세의 손 바뀜·두 번째 펜을 제거했습니다. 펜이 귀에 붙어 보이던 문제도 해당 자세만 추가 편집해 간격을 벌렸습니다.
- 계획 완료: 쓰기→웅크리기→도약→공중→착지→안정. 같은 손이 같은 연필·계획표를 계속 잡습니다. 초록 V는 2–5번 자세에만 있습니다.
- 열정 진행 중: 방망이의 어깨 옆 짧은 조각과 다리 옆 긴 조각을 제거하고, 오른쪽 손이 얇은 손잡이를 잡는 하나의 세운 방망이로 정리했습니다. 반대쪽 빈 주먹만 당기고 올렸다 내립니다.
- 열정 완료: 같은 방향으로 잡은 방망이 하나와 빈 주먹을 유지합니다. 불꽃 없이 폭죽과 점프, 착지, 안정으로 이어집니다. V를 넣지 않았습니다.
- 두 캐릭터 대기 폴더는 v6에서 파일 내용을 변경하지 않고 복사했습니다.

## 제작과 검증

내장 `image_gen`으로 기존 자세 이미지를 편집했습니다. 최초 프롬프트는 `prompts.json`, 소품 연속성 수정은 `prop-continuity-prompts.json`, 다섯 번째 펜 간격 수정은 `pose5-spacing-prompt.json`에 기록했습니다. 수정 전 이미지는 `reference/before-prop-review/`에 보존했습니다. 캐릭터를 코드 도형으로 새로 그린 v7은 사용하지 않았습니다.

`build_assets.py`는 이 폴더의 생성 원본만 읽어 팔레트·알파·위치·눈빛 픽셀을 정리하고 결과를 포장합니다. Python 3, Pillow, NumPy가 필요합니다. `python3 build_assets.py`로 PNG/GIF/PXO와 미리보기를 다시 만들 수 있습니다.

Pixelorama 1.2.3에서 네 PXO를 실제 읽어 GIF로 내보냈고 합성 픽셀을 PNG와 비교했습니다. Pixelorama가 내보낸 참고 GIF는 일부 유지 시간을 10ms씩 올림합니다. 기본 `<동작명>.gif`와 HTML은 표의 정확한 시간을 사용합니다. 참고 내보내기는 각 `pixelorama-export/`에 있습니다.

6프레임·해상도·색 수·알파·프레임 테두리·GIF 시간·PXO 합성 일치·대기 파일 동일성을 검증했습니다. 원본 시트와 최종 프레임을 직접 시각적으로 점검했습니다. HTML의 JavaScript 구문을 확인했으며 브라우저 상호작용을 실행 검증한 것은 아닙니다.

이전 디자인 폴더와 앱·위젯·설치·배포·사용자 계획 데이터는 변경하지 않았습니다.
