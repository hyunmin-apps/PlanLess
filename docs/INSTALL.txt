Study Glass 1.0.3 — 설치 스크립트 안내

공식 릴리스에서 StudyGlass-1.0.3-Install.command를 받으세요.
스크립트는 공증 전 앱이라는 점과 격리 해제 범위를 보여주고 y 입력을 받습니다.
공식 ZIP 다운로드 → SHA-256 확인 → 서명 구조 확인 → ~/Applications에 설치
→ Study Glass 앱의 격리 속성만 제거 → 실행 순서로 진행합니다.
관리자 암호나 Xcode는 필요하지 않습니다. macOS 14 이상이 필요합니다.
실행 중인 Study Glass는 자동 종료합니다. 3초 뒤에도 응답하지 않으면 강제 종료합니다.
저장하지 않은 편집 내용은 사라질 수 있으니 먼저 저장하세요. 기존 앱은 압축 백업하며 저장된 공부 기록은 유지합니다.

터미널에 아래 한 줄 전체를 복사해 실행하세요.
파일은 다운로드 폴더에 있어야 합니다.

/bin/bash "$HOME/Downloads/StudyGlass-1.0.3-Install.command"

$HOME이 현재 사용자 폴더를 자동으로 가리켜 사용자 이름을 바꿀 필요가 없습니다.
/bin/bash만 먼저 실행하지 말고 파일 경로까지 같은 줄로 실행하세요.
안내를 읽고 y를 입력하면 설치가 진행됩니다.
다른 폴더에 저장했거나 파일명 뒤에 (1) 등이 붙었다면 실제 경로에 맞춰주세요.
공증을 대체하지 않으며 설치자의 명시적인 실행이 필요합니다.

/Applications에 수동 설치한 앱이 있다면 새 앱은 ~/Applications에 별도로 설치됩니다.
설치 후 실행되는 새 앱을 사용하세요. 이전 앱은 자동 삭제하지 않습니다.

수동 설치: DMG를 Finder에서 열어 앱을 응용 프로그램 폴더로 복사합니다.
공증 경고에서 완료 → 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.
‘손상됨’ 또는 ‘컴퓨터를 손상시킴’ 경고는 별도로 확인해야 합니다.

기록 저장: ~/Library/Application Support/StudyGlass/state.json
공식 배포: https://github.com/hyunmin-apps/StudyGlass/releases

진행 중(◐)인 할 일은 날짜가 지나면 오늘로 자동 이동합니다. 미시작·통과·삭제 항목과 미래 계획은 이동하지 않습니다. 앱 재실행·날짜 변경 시 반영되며 위젯도 같은 기준으로 표시합니다.
