# 레서 통합 1.1.0 로컬 검증판 — 2026-10-18

앱 안, 기존 작은 창/바탕화면 모드, macOS 상단바에 레서를 추가했습니다. 별도 떠다니는 펫 창은 제거했습니다. 캐릭터와 목표를 선택하고 진행/완료를 누르면 기존 목표 상태가 저장됩니다. 계획 데이터 형식은 유지합니다.

## 상태 동작

- 기존 완료 기록은 앱 실행 시 다시 축하하지 않습니다.
- 알려진 목표가 완료로 바뀔 때 1.5초 동작을 5회, 총 7.5초 재생합니다. 연속 완료는 각 목표별로 차례대로 처리합니다. 같은 상태를 반복 저장해도 재시작하지 않습니다.
- 이후 진행 중인 유효 목표가 하나라도 남으면 진행 동작을 계속 재생하고, 없으면 포인터 방향의 전신 자세와 중립 눈깜빡임으로 돌아갑니다. 완료 취소·삭제는 해당 축하를 취소합니다.
- 시선은 얼굴만 분리해 회전하지 않습니다. v2 전신 포즈, 발 위치 고정, 비율 보존, 중간 자세, 방향 경계 여유를 사용합니다. 열정 레서 왼쪽 세 영역은 완만한 왼쪽 자세 하나를 공유합니다.
- 앱 전역 포인터 연결은 창 좌표로 변환하며 별도 입력 감시 권한을 요구하지 않습니다. 숨긴 창/레서에는 포인터 전달을 중단합니다. 화면이 바뀌지 않을 때는 캔버스/이미지를 다시 그리지 않습니다.

## 시스템 WidgetKit 위젯

기존 하루·주간 위젯에 상태별 대표 레서 이미지와 체크 링크를 추가했습니다. 체크는 `studyglass://goal?id=...&status=...`로 앱을 열어 상태를 변경합니다. 앱/상단바의 축하도 같은 상태 변경에 반응합니다.

WidgetKit은 지속 타이머·포인터 추적을 제공하는 앱 창과 다릅니다. 시스템 위젯에서 5회 프레임 재생이나 지속적인 진행 동작을 보장하지 않습니다. 갱신·완료 이미지 만료 시점도 시스템 정책의 영향을 받습니다. 새 AppIntent 버튼은 빌드 환경에 메타데이터 생성 도구가 없어 채택하지 않았습니다. 실행되지 않는 버튼 대신 기존 날짜 링크와 같은 방식의 체크 링크를 사용합니다.

## 확인한 범위

- Foundation 상태 테스트: 정확히 5회, 다른 목표 진행 유지, 대기 복귀, 반복 저장, 연속 완료 대기열, 완료 취소, 삭제/수정/이월 투영, 프레임 경계.
- 실제 웹 코드 테스트: 유효 목표 변경·저장, 삭제/잘못된 목표 거부, 로컬 이미지 로딩, 포인터 좌우 포즈, 캐릭터/상태 전환, 프레임 시간, 숨김·빈 목표.
- 이미지 검사: 승인된 진행·완료 24장 바이트 일치, 새 대기 24장 80×80/이진 투명도/발 높이, 가장자리 잘림 없음. 그림은 원본 시트와 축소 시트를 직접 검토했습니다. 소품 개수·해부학적 자연스러움을 자동 검사로 보증하는 것은 아닙니다.
- Apple Silicon에서 격리된 가짜 목표로 앱 UI 실행: 진행 중 표시, 완료 1/5 및 5/5, 대기 복귀, 기존 작은 창 배치, 두 캐릭터 선택을 확인했습니다. 실제 사용자 목표와 설치 앱은 변경하지 않았습니다.
- 기존 이월·AI 가져오기·일괄 삭제·위젯 모델 회귀 검사 통과.
- Universal arm64/x86_64 빌드·중첩 서명·개인 상태 미포함 검사. 실제 Intel Mac 실행은 확인하지 않았습니다.

이번 변경의 상단바 팝오버/시스템 위젯 클릭과 실바탕화면 재등록은 별도 UI 검증이 남아 있습니다. 새 버전 설치·원격 릴리스·공증은 수행하지 않았습니다. 이전 위젯 실기기 기록을 이번 버전 검증으로 간주하지 않습니다.
