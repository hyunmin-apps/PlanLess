## 0.1.2 — 설치 스크립트 추가

**Apple 공증 전 시험판입니다.** 설치자가 동의하면 Study Glass 앱에만 격리 속성을 제거합니다. Mac 전체 보안 설정은 변경하지 않습니다.

### 간편 설치

1. 아래 `StudyGlass-0.1.2-Install.command`를 다운로드합니다.
2. 실행한 뒤 안내를 읽고 `y`를 입력합니다.
3. 스크립트가 공식 ZIP 다운로드, 고정 SHA-256 대조, 서명 구조 검사, `~/Applications` 설치, 해당 앱 격리 해제와 실행을 진행합니다.

**스크립트 자체가 차단되면:** 터미널에 `/bin/bash `를 입력하고 다운로드한 `.command` 파일을 창으로 드래그한 뒤 Enter를 누르세요. 소스를 읽고 출처를 확인한 후 실행하세요. 관리자 암호나 Xcode는 필요하지 않습니다.

실행 중인 Study Glass는 먼저 종료하세요. 기존 `~/Applications` 앱은 별도 폴더에 백업하며 기록 파일은 건드리지 않습니다. `/Applications`의 기존 앱은 자동으로 삭제하지 않습니다.

### 검증 및 제한

macOS 14 이상 · Apple Silicon / Intel 공용. 공증 자체를 해결한 버전이 아니며, 관리되는 Mac의 정책을 우회하거나 모든 보안 차단을 해결하지는 않습니다. DMG·ZIP 수동 설치도 제공합니다. 위젯은 앱을 한 번 실행한 뒤 바탕화면의 위젯 편집에서 추가하세요.
