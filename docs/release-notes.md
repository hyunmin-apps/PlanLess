## 설치

**[설치 파일 다운로드](https://github.com/hyunmin-apps/StudyGlass/releases/download/v1.0.1/StudyGlass-1.0.1-Install.command)** — 이 파일 하나만 받으세요.

1. 실행 중인 Study Glass를 **⌘Q로 종료**합니다.
2. 받은 파일을 다운로드 폴더에 두고 터미널에서 아래 한 줄을 실행합니다.

```bash
/bin/bash "$HOME/Downloads/StudyGlass-1.0.1-Install.command"
```

3. 안내를 확인하고 `y`를 입력하면 설치와 앱 실행이 진행됩니다.

macOS 14 이상 · Apple Silicon / Intel 공용. 기존 할 일과 체크 기록은 유지됩니다.

**Apple 공증 전 시험판입니다.** 동의하면 Study Glass 앱에만 격리 속성을 제거합니다. 시스템 전체 보안 설정은 변경하지 않습니다.

## 1.0.1 변경

- 내장 공부 계획 제거: 새 설치는 오늘 날짜의 빈 계획으로 시작합니다.
- 직접 추가하거나 AI로 가져온 계획은 업데이트해도 유지합니다.
- 이전 앱은 압축 백업하고 교체합니다. 구형 설치기가 남긴 백업 앱도 압축하여 중복 실행·위젯 등록을 방지합니다.
- 새 앱과 위젯을 다시 등록합니다. 바탕화면 위젯의 배치는 유지하며, macOS 갱신에 시간이 걸릴 수 있습니다.

Assets의 ZIP은 설치 스크립트가 자동으로 받는 앱 파일입니다. 직접 다운로드할 필요 없습니다.
