# PlanLess 1.1.2

**계획은 가볍게, 실천은 바로.** 계획에 쓰는 시간을 줄이고 지금 할 일부터 시작하도록 앱 이름을 PlanLess로 바꿨습니다.

- 앱·상단바·위젯·설치 및 배포 파일의 새 이름 적용.
- 기존 Study Glass 설치를 PlanLess.app으로 교체하며 목표·설정·위젯 배치 유지.
- 계획단장/열정 레서: 진행 중 응원, 새 완료 시 정확히 5회 축하, 대기 시 전신 방향 포즈.
- 창 닫기 후 상단바·위젯 링크를 통한 재열기 충돌 수정.

배포 시 Assets의 `PlanLess-1.1.2-Install.command` 하나를 받아 실행하세요. 안내 확인 후 동의하면 공식 ZIP을 검증하고 설치합니다. 실행 중인 앱은 종료하므로 편집 내용을 먼저 저장하세요. 기존 앱은 압축 백업합니다.

macOS 14 이상 · Apple Silicon / Intel Universal. **Apple 공증 전 시험판**이며 앱에만 다운로드 격리를 해제합니다. 실제 Intel Mac 실행과 최소 OS 실기기 검증은 하지 않았습니다. 시스템 WidgetKit은 대표 정지 이미지를 표시하고 갱신 시점은 macOS가 정합니다.

이 문서는 다음 배포용입니다. GitHub에 새 버전을 배포했다는 뜻은 아닙니다.
