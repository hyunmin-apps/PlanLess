# 0.1.0 검증 기록

## 확인됨

- 개발 Apple Silicon Mac에서 앱 실행, 날짜 전환, 체크 저장·복원.
- macOS 위젯 갤러리에서 하루 목표 소/중/대 및 주간 목표 대 표시.
- 실제 바탕화면에 하루·주간 위젯 추가 및 계획 텍스트 확인.
- `studyglass://day/YYYY-MM-DD` 연결 시 앱에서 해당 날짜 열림.
- 앱 데이터와 위젯 스냅샷의 내용 일치 검사.

## 배포 검사

`tests/verify.py`는 앱과 위젯의 아키텍처, 외부 로컬 경로에 대한 의존성 부재, 중첩 코드 서명, 위젯 메타데이터, 기본 계획 일치, 개인 상태 파일 제외를 검사합니다.

GitHub Actions는 Apple Silicon과 Intel 러너에서 각 아키텍처의 빌드·배포 구조 검사와 앱 프로세스 시작 후 8초 생존을 검사합니다. 이 검사는 위젯의 실제 GUI 동작을 대신하지 않습니다.

## 남은 검증

- 실제 Intel Mac에서 앱 조작 및 바탕화면 위젯 배치.
- macOS 14 최소 지원 버전에서 설치와 GUI 조작.
- 다운로드 격리 속성이 있는 파일의 첫 설치 및 Developer ID 공증.
- 위젯의 상태 갱신 지연·장시간 동작.

초기 위젯 실행 문제는 실행 진입점을 `NSExtensionMain`으로 지정해 해결했습니다. [유사 사례](https://github.com/steipete/CodexBar/issues/1095)와 별개로 이 프로젝트에서는 갤러리 등록과 실제 위젯 표시를 직접 확인했습니다.
